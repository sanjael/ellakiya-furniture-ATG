# Sri Ilakkiya (ஸ்ரீ இலக்கியா) - Furniture, Vessels & Home Appliances

Official Web Application & Admin Management Portal for **Sri Ilakkiya (ஸ்ரீ இலக்கியா)**, Aranthangi.

## Features
- **Comprehensive Product Catalog**: Vessels, Kitchenware, Solid Teak & Steel Furniture, Home Appliances & Electronics.
- **Top Brand Showcase**: Philips, Prestige, Pigeon, Usha, Hero, Daikin, LG, Panasonic, Preethi, Butterfly, Hawkins, Samsung.
- **Direct WhatsApp Ordering & Inquiries**: Instant connection to shop owners with pre-filled product details.
- **Dedicated Admin Portal (`admin.html`)**: Manage product prices, special festive offers, and custom items with backend persistence.
- **Built-in Node.js Backend Server (`server.js`)**: Real-time REST API sync saving data to `store_data.json`.
- **Zero Third-Party Runtime Dependencies**: Native Node.js HTTP & gzip compression.

## Running Locally
```bash
npm start
```
or run `start.bat`.
Visit `http://localhost:3000/` or `http://localhost:3000/admin.html`.
